## The Output Error Instruction, OE

DESCMPTIUN The output error instruction, OE, is used to output the decimal equivalent of the last HP-GLerror (if any).

USES This instruction can be used to determine the type of the last error. It is useful when debugging programs or to determine if all data or instructions were accepted by the plotter. =

SYNTAX OE (terminator)

EXPLANATIONNo parameters are used. The instruction will execute even if no terminator is received.
