## C O N F I D E N T I A L

## GS ( k &lt;Function 265&gt;

```
[Name] MaxiCode: Select the mode [Format] ASCII GS ( k pL pH cn fn n Hex 1D 28 6B 03 00 32 41 n Decimal 29 40 107 3 0 50 65 n [Range] ( pL + pH × 256) = 3 ( pL =3, pH =0) cn = 50 fn = 65 50 ≤ n ≤ 54 [Default] n = 50 [Description] Selects the mode for the MaxiCode
```

|   n | Function        |
|-----|-----------------|
|  50 | Selects mode 2. |
|  51 | Selects mode 3. |
|  52 | Selects mode 4. |
|  53 | Selects mode 5. |
|  54 | Selects mode 6. |

- ■ Settings of this function affect the processing of Functions 281 and 282.

[Notes]

- ■ Settings of this function are effective until ESC @ is executed, the printer is reset, or the power is turned off.

[Model-dependent variations]

TM-T90 , TM-T20 , TM-T88IV , TM-T88V , TM-T70 , TM-P60

## TM-T90 , TM-T88IV , TM-T70
