## GS ( k &lt;Function 165&gt;

[Name] QR Code: Select the model [Format] ASCII GS ( k pL pH cn fn n1 n2 Hex 1D 28 6B 04 00 31 41 n1 n2 Decimal 29 40 107 4 0 49 65 n1 n2 [Range] ( pL + pH × 256) = 4 ( pL = 4, pH = 0) cn = 49 fn = 65 n1 = 49, 50 n2 = 0 [Default] n1 = 50, n2 = 0 [Description] Selects the model for QR Code.

|   n1 | Function         |
|------|------------------|
|   49 | Selects model 1. |
|   50 | Selects model 2. |

- ■ Settings of this function affect the processing of Functions 181 and 182.

[Notes]

- ■ Settings of this function are effective until ESC @ is executed, the printer is reset, or the power is turned off.

[Model-dependent variations]

TM-T90 , TM-P60 , TM-T20 , TM-T88V

## TM-T90

This model does not support this function.

## TM-P60

TM-P60 with peeler supports this function.
