## C O N F I D E N T I A L

- ❏ Specify the size of image data not to exceed the current print area.
- ❏ A graphic that exceeds the size limit of ( yL + yH × 256) can be printed by the repeated use of the combination of this function and &lt;Function 50&gt; of this command. In that case, the performance may be best when the vertical size is specified as [120 ≤ ( yL + yH × 256) ≤ 400 (reference value)] by this function. However, the value is only a reference value. The most suitable vertical size depends on the specifications of the PC or radio frequency energy transmitted by wireless communication.

If the time of processing this function cannot be shortened when processing the above-mentioned item, the printing result may include horizontal stripes. In this case, transmit the graphic data specified within the maximum range of ( yL + yH × 256) one time to prevent the horizontal stripe but the performance will decrease.
