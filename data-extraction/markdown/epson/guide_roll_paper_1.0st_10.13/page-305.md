## TM-J2000/J2100

This printer supports the NV graphics function of GS ( L and GS 8 L .

It is recommended that NV graphics function ( GS (L / GS 8 L ) be used.

The data of this command and record data of user NV memory ( GS ( C ) are stored in the same definition area. The total data of NV bit image and GS ( C record can be defined up to 384 KB.

## TM-T20 , TM-T88IV , TM-T88V , TM-T70

This printer supports the NV graphics function of GS ( L and GS 8 L. It is recommended that NV graphics function (GS (L / GS 8 L) be used. The domain for saving data with this command is 256 KB.
