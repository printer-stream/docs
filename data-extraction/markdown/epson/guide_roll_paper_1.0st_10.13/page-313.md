## TM-J2000/J2100

This printer supports downloaded graphics functions of GS ( L and GS 8 L . It is recommended that the downloaded graphics function ( GS ( L / GS 8 L ) be used.

A downloaded bit image and a user-defined character cannot be defined simultaneously.

## TM-T90

For other than the Japanese model, a downloaded bit image and a user-defined character cannot be defined simultaneously when memory switch 8-7 is ON. See Function 3 of GS ( E for the memory switch.

## TM-T20 , TM-T88IV , TM-T88V , TM-T70

A downloaded bit image and a user-defined character cannot be defined simultaneously.
