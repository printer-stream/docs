## Format

| Hex     |   1B |   23 |
|---------|------|------|
| Decimal |   27 |   35 |

## Function

Cancels any controls on the MSB (bit number 7) set by the ESC = or ESC &gt; commands; printer then accepts all MSB data as is

## Default

No MSB control

## Notes

This is a nonrecommended command; most computer systems no longer require MSB control.

## Printers not featuring this command

ActionPrinter Apex 80, ActionPrinter T-1000, ActionPrinter 2000, ActionPrinter 2250, LX100, LX-300, LX-400, LX-800, LX-810, LX-850, LX-1050, T-1000

## Model-dependent variations

None
