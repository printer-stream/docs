## Format

ASCII ESC =

| Hex     |   1B |   3D |
|---------|------|------|
| Decimal |   27 |   61 |

## Function

Sets the MSB (bit number 7) of all incoming data to 0

## Default

No MSB control

## Notes

- This is a nonrecommended command; most computer systems no longer require MSB control.
- All data is affected, including graphics data.

## Printers not featuring this command

ActionPrinter Apex 80, ActionPrinter T-1000, ActionPrinter 2000, ActionPrinter 2250, LX100, LX-300, LX-400 LX-800, LX-810, LX-850, LX-1050

## Model-dependent variations

None
