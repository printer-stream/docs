## Format

ASCII

ESC s n

```
Hex 1B 73 n Decimal 27 115 n
```

## Parameter range

n = 0, 1, 48, 49

## Function

Controls printing speed as follows:

n = 0 or 48

Prints at normal speed

1 or 49

Prints at low speed

## Default

Normal-speed printing

## Notes

This is a nonrecommended command.

Printers not featuring this command

DFX-5000, DFX-8000, DFX-5000+

Model-dependent variations

None
