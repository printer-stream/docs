## 2.  COMMAND FUNCTION LIST

## · Standard Commands

| Class                        | Commands   | Name                                           |
|------------------------------|------------|------------------------------------------------|
| Font style And character set | ESC RS F   | Select font                                    |
| Font style And character set | ESC GS t   | Specify code page                              |
| Font style And character set | ESC GS =   | Write blank code page data                     |
| Font style And character set | ESC R      | Specify international character set            |
| Font style And character set | ESC /      | Specify/cancel slash zero                      |
| Font style And character set | ESC SP     | Set ANK right space                            |
| Font style And character set | ESC M      | SpecifyANK 12 dot pitch                        |
| Font style And character set | ESC P      | SpecifyANK 15 dot pitch                        |
| Font style And character set | ESC :      | SpecifyANK 16 dot pitch                        |
| Font style And character set | ESC g      | SpecifyANK 14 dot pitch                        |
| Character expansion settings | ESC i      | Set/cancel the double wide/high printing       |
| Character expansion settings | ESCW       | Set/cancel the double wide printing            |
| Character expansion settings | ESC h      | Set/cancel the double high printing            |
| Character expansion settings | SO         | Set double wide printing                       |
| Character expansion settings | DC4        | Cancel double wide printing                    |
| Character expansion settings | ESC SO     | Set printing magnified double character height |
| Character expansion settings | ESC DC4    | Cancel printing magnified character height     |
| Print modes                  | ESC E      | Select emphasized printing                     |
| Print modes                  | ESC F      | Cancel emphasized printing                     |
| Print modes                  | ESC -      | Select/cancels underling mode                  |
| Print modes                  | ESC _      | Select/cancels upperline mode                  |
| Print modes                  | ESC 4      | Select white/black inverted printing           |
| Print modes                  | ESC 5      | Cancel white/black inverted printing           |
| Print modes                  | SI         | Select upside-down printing                    |
| Print modes                  | DC2        | Cancel upside-down printing                    |
| Line spacing                 | LF         | Line feed                                      |
| Line spacing                 | CR         | Carriage return (same as line feed)            |
| Line spacing                 | ESC a      | Feed paper n lines                             |
| Line spacing                 | ESC z      | Select line feed amount                        |
| Line spacing                 | ESC 0      | Specify line spacing to 3 mm                   |
| Line spacing                 | ESC J      | n/4 mm line feed                               |
| Line spacing                 | ESC I      | n/8 mm line feed                               |
