## · Page Mode Commands

| Class     | Commands   | Name                                                   |
|-----------|------------|--------------------------------------------------------|
| Page Mode | ESC GS P 0 | Selects page mode                                      |
| Page Mode | ESC GS P 1 | Cancels page mode                                      |
| Page Mode | ESC GS P 2 | Select printing direction                              |
| Page Mode | ESC GS P 3 | Set print region                                       |
| Page Mode | ESC GS P 4 | Specify character vertical direction absolute position |
| Page Mode | ESC GS P 5 | Specify character vertical direction relative position |
| Page Mode | ESC GS P 6 | Prints                                                 |
| Page Mode | ESC GS P 7 | Cancel printing and page mode                          |
| Page Mode | ESC GS P 8 | Cancel print data                                      |

## · Text Search Commands

| Class       | Commands             | Name                                                                     |
|-------------|----------------------|--------------------------------------------------------------------------|
| Text Search | ESC GS ) B (fn = 48) | Enable and disables text search                                          |
| Text Search | ESC GS ) B (fn = 49) | Set the number of times to run the text search macro                     |
| Text Search | ESC GS ) B (fn = 50) | Set to print the string that matches in the text search                  |
| Text Search | ESC GS ) B (fn = 64) | Define the text search string                                            |
| Text Search | ESC GS ) B (fn = 65) | Define the text search macro                                             |
| Text Search | ESC GS ) B (fn = 80) | Register text search settings and definitions in the non-volatile memory |
| Text Search | ESC GS ) B (fn = 81) | Initialize text search settings and definitions                          |
| Text Search | ESC GS ) B (fn = 96) | Print the text search settings and definitions                           |
| Text Search | ESC GS ) B (fn = 97) | Run the text search macro                                                |
