Name

Select international characters

Code

ASCII ESC R n

Hex. 1B 52 n

Decimal 27 82 n

Defined Region

Spec.  A:  0 ≤ n ≤ 13

Spec.  B:  0 ≤ n ≤ 17

Initial Value

n = 0

Function

Selects the character set for the country listed below.

|  13 | Korea         |
