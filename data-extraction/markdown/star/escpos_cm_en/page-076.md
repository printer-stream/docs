## ESC t n

Name

Select character code table

Code

ASCII ESC t n

Hex. 1B 74 n

Decimal 27 116 n

Defined Region

Spec.  A:  0 ≤ n ≤ 5, 16 ≤ n ≤ 19, n = 255

Spec.  B:  0 ≤ n ≤ 5, 16 ≤ n ≤ 26, n = 255

Initial Value

n = 0

Function

Select page n of the character code table.

Spec.  A:

n
