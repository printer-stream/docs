Name

Select Font

Code

ASCII ESC RS F n

Hex. 1B 1E 46 n

Decimal 27 30 70 n

Defined Region

0 ≤ n ≤ 1, n = 16

Initial Value

n = 0

Function

- Selects the font.

|   n | Font                  |
|-----|-----------------------|
|   0 | Font A (12 x 24 dots) |
|   1 | Font B (9 x 24 dots)  |
|  16 | OCR B (16 x 24 dots)  |

The functions outlined below are disabled when the OCR B font is selected.

- Code page
- Blank code page
- Country characters
- Slashed zero

Character modifier, expansion and external character settings are disabled when using the OCR B font for reading using a scanner.  Check the OCR B font in actual use before using.
