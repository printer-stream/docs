The OutputExtended Error Instruction,
ESC.E
UESCRIPHUN The output extended error instruction, ESC . E, outputs
a number which deﬁnes any RS-232—Crelated I/O error and turns off
the front-panel ERRORlight.
USES
The instruction is used to deﬁne what type of RS-232-Crelated
I/O error has occurred,if any.
