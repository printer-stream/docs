Note:
The error recovery command is valid only if a recoverable error (excluding automatically recoverable 
errors) occurs. If a recoverable error occurs, the printer recovers from the error upon receipt of an error 
recovery command from the driver after the cause of the error is eliminated. Turning the printer’s power 
off and on is not required.
Unrecoverable errors
Normal printer operation is no longer possible when unrecoverable errors occur. The printer 
must be repaired. 
Note:
When an unrecoverable error occurs, turn off the power supply immediately.
