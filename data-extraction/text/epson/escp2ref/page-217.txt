ESC =
Set MSB to 0
ESC/P 2
ESC/P
Format
ASCII
ESC
=
Hex
1B
3D
Decimal
27
61
Function
Sets the MSB (bit number 7) of all incoming data to 0
Default
No MSB control
Notes
• 
This is a nonrecommended command; most computer systems no longer require MSB
control.
• 
All data is affected, including graphics data.
