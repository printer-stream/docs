Individual Command Explanations        C-49
BS
Backspace
9-Pin ESC/P
Format
ASCII
BS
Hex
08
Decimal
8
Function
Moves the print position to the left a distance equal to one character in the current pitch
plus any additional intercharacter space
Notes
• 
This is a nonrecommended command.
• 
The printer ignores this command if it would move the print position to the left of the
left margin.
Printers not featuring this command
None
Model-dependent variations
None
