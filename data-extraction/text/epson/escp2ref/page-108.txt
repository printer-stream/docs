ESC P
Select 10-cpi
9-Pin ESC/P
Format
ASCII
ESC
P
Hex
1B
50
Decimal
27
80
Function
Selects 10-cpi character pitch
Default
10-cpi characters
Notes
If you change the fixed-pitch setting with this command during proportional mode
(selected with the ESC p command), the change takes effect when the printer exits
proportional mode.

None
