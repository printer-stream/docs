ESC g
Select 10.5-point, 15-cpi
ESC/P 2
ESC/P
Format
ASCII
ESC
g
Hex
1B
67
Decimal
27
103
Function
Selects 10.5-point, 15-cpi character printing
Default
10.5-point, 10-cpi characters
Notes
• 
This command cancels the HMI set with the ESC c command.
• 
This command cancels multipoint mode.
• 
If you change the pitch with this command during proportional mode (selected with
the ESC p command), the change takes effect when the printer exits proportional mode.
Printers not featuring this command
None
