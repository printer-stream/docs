ESC #
Cancel MSB control
ESC/P 2
ESC/P
Format

#
Hex

Function
Cancels any controls on the MSB (bit number 7) set by the ESC = or ESC > commands;
printer then accepts all MSB data as is
Default
No MSB control
Notes
This is a nonrecommended command; most computer systems no longer require MSB
control.
