Each dot column requires two bytes of data. The first byte represents the top 8 dots in the
print head. Bit 0 (the LSB) in the second byte represents the ninth (bottom) dot in the print
head; the remaining
7 bits are ignored.
Notes
• 
This is a nonrecommended command; use the ESC * command instead.
• 
Graphics data that would print beyond the right-margin position is ignored.
• 
Bit-image graphics can be printed on the same line as text.
