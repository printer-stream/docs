Parameter range
0 < n ≤ 127
0 < (current line spacing) × n < (page length)
Function
Sets the bottom margin on continuous paper to n lines (in the current line spacing) from the
top-of-form position on the next page.
Default
Either no margin or 1-inch margin, depending on the DIP-switch setting
Notes
• 
The bottom margin set with the ESC N command is ignored when printing on single
sheets.
• 
With ESC/P 2 printers, use the ESC ( c command instead; this allows you to set both top
and bottom margins on continuous and single-sheet paper.
• 
Sending this command cancels the top-margin setting.
• 
This was formerly called the “Set skip-over-perforation” command.
