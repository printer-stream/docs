ESC SP
Set intercharacter space

Decimal

n
Parameter range
0 ≤ n ≤ 127
Function
Increases the space between characters by n/180 inch in LQ mode and n/120 inch in draft
mode
Default
No extra space
Notes
• 
This command cancels the HMI (horizontal motion unit) set with the ESC c command.
• 
The extra space set with this command doubles during double-width mode.
