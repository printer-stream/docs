Individual Command Explanations        C-125
ESC -
Turn underline on/off
ESC/P 2
ESC/P

Parameter range
n = 0, 1, 48, 49
Function
Turns on/off printing of a line below all characters and spaces following this command:
n = 1 or 49
Turns underline on
0 or 48
Turns underline off
Default
Normal (non-underlined) printing
Notes
• 
The underline is printed with the following characteristics: draft, LQ, bold, or double-
strike.
• 
The underline is not printed across the distance the horizontal print position is moved
with the following commands:
ESC $
ESC \ (when the print position is moved to the left)
HT
• 
Graphics characters are not underlined.

None
