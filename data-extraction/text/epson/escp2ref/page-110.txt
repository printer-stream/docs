ESC M
Select 12-cpi
9-Pin ESC/P
Format
ASCII
ESC
M
Hex
1B
4D

Function
Selects 12-cpi character pitch
Default
10-cpi characters
Notes
If you change the pitch with this command during proportional mode (selected with the
ESC p command), the change takes effect when the printer exits proportional mode.
