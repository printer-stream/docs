Additional Functions and Functional Improvements
Print Speed
The TM-T88IV prints faster than the TM-T88III.
Note) When the printer prints with the default print density level at 24V and 25°C {77°F}.
High-Speed Graphic Printing
With the TM-T88IV, high-speed graphic printing is possible. (print speed: 200 mm/s at 
maximum)
Two-Dimensional Code
With the TM-T88IV, two-dimensional code (PDF417, QR code) printing is possible.
Number of Characters
For the TM-T88IV, special characters (845) are added.
