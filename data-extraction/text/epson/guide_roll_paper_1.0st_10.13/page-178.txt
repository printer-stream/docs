SETTING COMMAND
[Name]
Set print area in page mode
[Format]
ASCII
ESC W
xL   xH   yL   yH   dxL   dxH   dyL   dyH
Hex
1B
57
xL   xH   yL   yH   dxL   dxH   dyL   dyH
Decimal
27
87
xL   xH  yL   yH   dxL   dxH   dyL   dyH
[Range]
0 ≤  xL, xH, yL, yH, dxL, dxH, dyL, dyH  ≤  255
(except for dxL = dxH = 0 or dyL = dyH = 0)
[Default]
Horizontal logical origin and vertical logical origin= 0
xL = 0, xH = 0, yL = 0, yH = 0
Print area width and print area height = entire printable area
