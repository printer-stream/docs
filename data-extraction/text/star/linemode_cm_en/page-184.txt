• This status is valid only on models provided with a presenter. Models not provided with a presenter should send this 
status fixed at “0.”   
• This status is made valid and invalid using the memory switch only on models provided with a presenter.   
When valid, the presenter paper position status is updated, but when invalid, the presenter paper position status is fixed 
at “0” and there is no change in status.
