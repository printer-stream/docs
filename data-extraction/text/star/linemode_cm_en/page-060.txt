[Defined Area] 
0≤n1≤8,  48≤n1≤56 (”0≤n1≤”8”) 
 
1≤n2≤4,  49≤n2≤52 (”1”≤n2≤”4”) 
 
1≤n4≤255  
 
 
 
n3 (bar code mode), d (bar code data), k (bar code data count) definitions differ according to the 
type of bar code.   
[Initial Value] 
- - - 
[Function] 
Bar code printing is executed according to the following parameters.  
 
If n1, n2, n3 and n4 are acquired and detected to be out of the defined area, data up to RS is 
discarded.
