[Initial Value] 
Memory switch setting 
[Function] 
Sets print speed.   
 
This command stops printing to be executed.   
 
Because two-color print mode prints in one speed, the speed settings with this command are 
invalid.  This command setting becomes valid when returned from the two-color print mode to the 
single color print mode.
