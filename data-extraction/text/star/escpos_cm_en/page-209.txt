Function	
Initializes registered data in the non-volatile memory of the Auto Logo function.  
	
After initialization, the printer is reset.  
	
This command is ignored when Auto Logo is being executed.
	
 Considering the non-volatile memory service life, avoid using this command frequently.
	
	
The default values of the Auto Logo function are below.
