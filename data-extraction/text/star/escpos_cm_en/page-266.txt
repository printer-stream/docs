Function		
Hold print sensor installation data is sent in the format below.
<ESC> <GS> “)” “s” pL pH fn m n <NUL>
n
installation data
0
Not installed
1
Installed
When outside the parameter definitions or out of the specified sensor installation 
specifications, <ESC> <GS> “)” “s” <0> <0> fn <LF> <NUL> is returned.
If unprinted data exists in the image buffer at the time this command is processed, the 
command is executed without executing printing first.
