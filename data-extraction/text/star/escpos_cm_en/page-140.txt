 GS T n 
Name	
Move to top of line 
Code	
ASCII	
GS	
T	
n
	
Hex.	
1D	
54

Decimal	
29

n
Defined Region	
n = 0,1,48,49
Function	
Moves print position to top of line.  
	
•	This command is effective only in standard mode. It is ignored in page mode.  
n
Function
0, 48
After erasing data in the printer buffer, it moves the print position. 
1, 49
After printing data in the printer buffer, it moves the print position.
