Defined Region	
0 ≤ n ≤ 3, 48 ≤ n ≤ 51
Initial Value	
n = 0
Function 	
Selects the character printing direction and starting point in page mode.  
Details 	
•	Executes only a printer internal flag operation when this command is input in standard mode. 
	
The command does not affect printing in standard mode.  
	
•	The character expansion starting point is in the print region specified by ESC W (Set print 
region in page mode). 
	
•	The basic calculated pitch (x or y) used with the following commands differs according to the 
starting point.  
	
a. If the starting point is upper left or lower right (feeds paper and expands characters in the 
vertical direction)
	
	 Commands using x	:	
	ESC SP, ESC $, ESC \, FS S
	
	 Commands using y	:	
	SC 3, ESC J, GS $, GS \
	
b. If the starting point is upper right or lower left 
	
	 Commands using x	:	
	ESC 3, ESC J, GS $, GS \
	
	 Commands using y	:	
	ESC SP, ESC $, ESC \, FS S
