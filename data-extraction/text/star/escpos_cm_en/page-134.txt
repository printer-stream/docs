GS H n 
Name	
Select HRI character print position 
Code	
ASCII	
GS	
H	
n
	
Hex.

n
Defined Region	
0 ≤ n ≤ 3, 48 ≤ n ≤ 51
Initial Value	
n = 0
Function 	
Selects the printing position of HRI characters when printing bar codes.  
n
Printing Position 
0, 48
No print
1, 49
Above bar code
2, 50
Below bar code
3, 51
Above and below bar code 
(both) 
Details 	
• HRI is an acronym for Human Readable Interpretation.  
	
• HRI characters are printed with fonts selected by GS f (Select HRI character font).  
Reference 	
GS f, GS k
