## **ESC GS / W** 

Name Register Auto Logo setting to non-volatile memory Code ASCII ESC  GS / W Hex. 1b 1d 2f 57 Decimal 27 29 47 87 --Defined Region Initial Value --Function Registers Auto Logo setting to non-volatile memory After registration, the printer is reset. This command is ignored when Auto Logo is being executed. Considering the non-volatile memory service life, avoid using this command frequently. Reference ESC GS / C, ESC GS / 1, ESC GS / 2, ESC GS / 3, ESC GS / 4, ESC GS / 5, ESCGS/6
