## **C O N F I D E N T I A L** 

## TM-P60 

**The [data value (** k **) + control information data value (see the table below)] area of the NV graphics data domain is used when this function is executed.** 

|**Condition**|**Control information data value**|
|---|---|
|**If data value (**k**) is odd number**|**32 bytes**|
|**If data value (**k**) is even number**|**33 bytes**|
