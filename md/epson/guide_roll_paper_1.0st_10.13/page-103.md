## **C O N F I D E N T I A L** 

## TM-U230 

**The vertical motion unit is 0.176 mm {1/144 inch}. This value equals a half dot pitch. This command does not use the horizontal motion unit because this printer does not support page mode. The default value is (** n **= 24).**
