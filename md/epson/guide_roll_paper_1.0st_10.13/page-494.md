**A criterion density is the print density set by Function 5 (** a **= 5) of** GS ( E **.** 

## **The print density actually set is as follows.** 

**For Example: If (** m **= 4) is specified when 90% in a standard density is set, the print density becomes 110% [90%** × **120%].** 

**The print density can be only within the range of 70% to 130%. When it is set to exceed 130%, the print density becomes 70% or 130%.** 

**For example: If (** m **= 6) is specified at 120% in a standard density, the print density becomes 130% though the calculated value is 150% [120%** × **130%].**
